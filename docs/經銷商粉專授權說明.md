# 粉專協作授權說明（給經銷商）

> 給總公司對外溝通用的草稿。`{公司BM_ID}` 等佔位符待公司 Business Manager 建立後填入。
> 對應技術方案：**Partner Access（合作夥伴分享）**，經銷商保留粉專所有權、隨時可撤銷。

---

## 一、這是要做什麼？

總公司希望協助您**統一發布貼文到您的 Facebook 粉絲專頁**，確保各地行銷素材與品牌形象一致、節省您自行發文的時間。

為此，需要您把粉專**「分享協作」**給總公司——這不是把粉專交出去，而是像「多請一位小編幫忙發文」。

## 二、您需要做什麼？（一次性，約 5 分鐘）

1. **確認粉專由「企業管理平台（Meta Business Manager）」管理**
   - 若還沒有，請至 [business.facebook.com](https://business.facebook.com) 免費建立一個企業帳號，並把您的粉專加進去（企業設定 → 帳號 → 粉絲專頁 → 新增）。

2. **把粉專分享給總公司**
   - 進入 **企業設定 → 帳號 → 粉絲專頁 → 選擇您的粉專**
   - 點 **「指派合作夥伴」** → 選 **「用企業編號（Business ID）」**
   - 輸入總公司企業編號：**`{公司BM_ID}`**
   - 權限勾選：**「管理粉絲專頁」中的「建立內容 / 發布貼文」**（不需給「管理粉專」的完整權限）

3. 完成，告訴總公司您的**粉專名稱**即可。

## 三、為什麼這是安全的？

- ✅ **您保留粉專的完整所有權**，總公司只是「被授權協作發文」的合作夥伴。
- ✅ **您隨時可一鍵撤銷**：企業設定 → 粉絲專頁 → 合作夥伴 → 移除，立即生效。
- ✅ 總公司**無法**變更您的粉專所有權、無法把粉專轉走、無法刪除您的粉專設定。
- ✅ **不需要提供您的 Facebook 帳號或密碼**給任何人。
- ✅ 您自己仍可正常管理、發文、查看數據，協作不影響您原本的操作。

## 四、如何隨時撤銷？

企業設定 → 帳號 → 粉絲專頁 → 選擇粉專 → 合作夥伴 → 找到總公司 → **移除存取權**。撤銷後總公司立即無法再發文，您的粉專完全不受影響。

## 五、常見問題

- **Q：總公司會看到我的私人帳號嗎？** 不會。協作只在粉專層級，與您的個人帳號無關。
- **Q：以後不想合作了怎麼辦？** 隨時依第四點撤銷，無任何後續綁定。
- **Q：一定要建企業管理平台嗎？** 是，這是 Meta 官方的安全協作機制；建立免費、約 3 分鐘。
