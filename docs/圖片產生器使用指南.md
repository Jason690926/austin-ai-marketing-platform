# 圖片產生器使用指南

給操作者的速查表：圖片產生器每一個欄位的意思 + 怎麼選。由上到下對應 UI 順序。

---

## 🧭 先記住「三條軸」（最容易混的地方）

這三個欄位**垂直獨立、可自由組合**：

| 軸 | 欄位 | 控制什麼 |
|---|---|---|
| 構圖**從哪來** | 背景場景模式 | 模板 / 參考圖 / 自己描述 |
| **光線氛圍** | 風格調性 | 暗調 / 暖調 / 自然光… |
| **寫實 ↔ 超現實** | 創意尺度 | 寫實融入 / 巧思點綴 / 超現實大膽 |

範例組合：
- 「自由描述『球場』＋ 戶外自然 ＋ 超現實大膽」= 大膽的球場主視覺 KV
- 「自由描述『客廳有足球』＋ 溫馨暖調 ＋ 寫實融入」= 正常的世足借勢居家圖

---

## 1️⃣ 品牌／門市（床墊 / 寢具）

要做哪個品牌的圖。
- **床墊** = Sleeptrain 席樂頓 → 飯店奢華調（深木、暖鎢絲光、五星飯店感）
- **寢具** = AUSTIN 奧斯汀 → 溫暖生活調（Kinfolk / MUJI、自然光、居家溫度）

⚠️ 選錯品牌，AI 的整體美學基調會跑掉。

## 2️⃣ 商品圖（選填）⭐ 最關鍵的決定

上傳「真實商品照」→ AI **完全保留商品原樣，只重生背景／氛圍**。
- **上傳**：適合「我有實品照，想換場景 / 做成廣告」。
- **不傳**：AI 用品牌通用形象自由發揮。
- ⚠️ **常見雷**：傳「整房情境照」時，AI 只能「換房間背景」，跟「室外場景」需求會打架（→ 產品漂浮 / 拼貼感）。**若要自由換場景，傳乾淨的商品照**（攤平 / 疊放 / 純色背景）效果最好；若就是要用整房照，場景描述就別離開室內。

## 3️⃣ 產圖層級（決定「誰寫文字、誰想場景」）

| 層級 | 意思 | 什麼時候選 |
|---|---|---|
| **底圖模式** | 乾淨底圖、**不燒任何字**、留白給後製 | 想自己用設計軟體排版上字 |
| **完整廣告** | **你填文字 → AI 把字燒進圖** | 要一張可直接用的成品廣告 |
| **AI 全權自主** | 只給商品 brief，**AI 自己想場景＋寫文案＋排版** | 沒想法、想一條龍生多張變體 |

## 4️⃣ 背景場景模式（底圖／完整廣告才有；AI 全權自主會隱藏）

構圖**從哪裡來**：
- **場景模板**：從預設場景挑（最穩、最快）。
- **參考圖片**：上傳參考圖，AI 照它的構圖／角度／光線做（想複製某張版面時用）。
- **自由描述**：自己打字描述場景（最自由，但描述要**具體**，否則容易怪）。

## 5️⃣ 場景描述 / 場景選單（跟著上一格變）

- 選「自由描述」→ 這裡打場景文字（如「溫馨客廳，地上有一顆足球」）。
- 選「場景模板」→ 這裡變預設場景選單。
- 💡 **借勢（世足 / 節慶）就寫在這裡當情境**（借勢是「內容」，不是寫實度）。

## 6️⃣ 風格調性（光線氛圍）

控制**打光與色調**：
- **自動**：AI 依品牌決定（不確定就選這個）。
- **飯店暗調**：低光、戲劇陰影（高級感）。
- **溫馨暖調**：暖色居家（寢具最常用）。
- **簡約清爽**：明亮乾淨。
- **戶外自然**：自然光戶外。
- **自由描述**：自己打光線需求（如「強烈側光打在布料上」）。

## 7️⃣ 廣告文字內容（只有「完整廣告」出現）

要燒進圖的字：
- **廣告標題**（必填）：最大、最吸睛那句。
- **副標題**（選填）：標題下方補充。
- **背書標語**（選填）：小字信任感（如「正版授權 SNOOPY」）。
- **產品賣點**（選填，最多 3 項）：條列賣點。

💡 填太少（只有標題）→ 系統會**自動切「極簡留白」版面**，讓「少」變「精」、版面不會空。想要層次就多填 1–2 個賣點 ＋ 背書。
⚠️ AI **不會幫你捏造價格 / 數字 / 認證 / 背書 / 療效**（合規鎖死），這些一定要你自己填。

## 8️⃣ 商品 brief ＋ 變體數（只有「AI 全權自主」出現）

打商品資訊（名稱 / 材質 / 賣點 / 調性），再設定要幾張「型錄風」＋ 幾張「生活風」變體。每張變體 × 每個尺寸 = 一次產圖。

## 9️⃣ 創意尺度（所有層級都有）— 寫實 ↔ 超現實

控制**寫實程度 / 創意大膽程度**：

| 選項 | 意思 | 什麼時候選 |
|---|---|---|
| **寫實融入**（預設） | 產品自然落地、真實接地陰影、不漂浮 | 要正常、可信、像實拍的圖 |
| **巧思點綴** | 寫實為主 ＋ 一個設計巧思 | 想有點設計感但不脫離真實 |
| **超現實大膽** | 刻意的超現實 KV（光線統一、概念清楚） | 想做大膽創意主視覺，做成「作品」而非「拼貼」 |

💡 上次「床漂浮在球場」的怪圖 → 選 **寫實融入** 會自然落地有陰影；想保留那種大膽概念 → 選 **超現實大膽**（AI 會把它做得光線統一、像完整作品）。

## 🔟 尺寸規格（可多選 ＋ 自訂像素）

要產的圖比例：
- 正方形 (1:1, IG)、直式 (4:5)、限時 (9:16, Stories)、橫式 (16:9, FB)、廣告橫幅 (1.91:1)、寬屏 (21:9)
- 或**自訂像素**（256–4096）
- **可一次多選**，每個尺寸各產一張。

## ✅ 快速決策範例

| 我想要… | 商品圖 | 層級 | 場景模式 | 風格調性 | 創意尺度 |
|---|---|---|---|---|---|
| 把實品換個漂亮場景 | 上傳乾淨商品照 | 底圖模式 | 自由描述 | 溫馨暖調 | 寫實融入 |
| 一張可直接發的成品廣告 | 上傳商品照 | 完整廣告 | 自由描述 | 自動 | 寫實融入 |
| 大膽的節慶借勢主視覺 | 視情況 | 完整廣告 | 自由描述（寫借勢情境） | 戶外自然 | 超現實大膽 |
| 懶得想，讓 AI 一次生多張 | 上傳商品照 | AI 全權自主 | （隱藏） | （隱藏） | 寫實融入 |
